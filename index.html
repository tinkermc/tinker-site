How it Works

Tinker Dash is the app on your PC where you click and manage. Tinker Agent runs on your server PC and does the work. One Agent can run many servers, and the same computer can run the Agent, Dash, and play the server at the same time.

    Install the Agent

    One command sets up the server PC: Java, the always-on service, the firewall and a password. An old PC works great.

  2. 02

    Connect Dash

    Open Tinker Dash and enter the address and token the installer gave you. Dash remembers it and reconnects on its own.

Questions

Discord Docs
What do I need to run Tinker?+

A Windows PC for Tinker Dash, and a Linux machine for Tinker Agent. An old PC works great. The Agent installs Java for you. Vanilla, Paper, Fabric and NeoForge servers are supported.

What's the difference between Dash and Agent?+

Tinker Dash is the app on your PC where you click, browse and manage. Tinker Agent is a small program on your server PC that actually runs your Minecraft servers. Dash sends instructions and the Agent does the work.

How is this different from other server panels?+

Tinker is a desktop app, not a web panel you host and secure yourself. You get the console, players, world tools and server setup in one place, without touching the command line.

Is Tinker free?+

Yes. Tinker Dash and Tinker Agent are free. Tinker Plus is an optional $4.99/month upgrade with extras like the Connection Tunnel and cloud backups.

Can I move my servers from Crafty Controller?+

Yes. The Agent finds Crafty's servers automatically, or you can point it at any folder. It copies the server in and leaves the original untouched. Stop the server in Crafty first.

How do I manage my server when I'm away from home?+

Use Tailscale for free, or turn on the Connection Tunnel with Tinker Plus. Never open the Agent's port (7122) to the internet.

Are you affiliated with Mojang or Microsoft?+

No. Tinker is an independent project and isn't affiliated with or endorsed by Mojang or Microsoft.
